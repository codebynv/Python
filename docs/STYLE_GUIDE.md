# Python Style Guide

## Naming

Use descriptive snake_case names for variables and functions and PascalCase for classes.

## Functions

Prefer small functions with one clear responsibility.

## Imports

Keep imports organized and remove unused dependencies.

## Errors

Raise or handle specific exceptions instead of catching every exception indiscriminately.

## Documentation

Document public functions when their behavior is not obvious from the signature.

## Readability

Prefer straightforward code over clever one-liners when the latter make the logic harder to understand.
