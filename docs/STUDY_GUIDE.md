# Python Study Guide

This repository is used for Python coursework and practice.

## Core revision path

1. Python syntax and data types
2. Conditions and loops
3. Functions
4. Strings and collections
5. File handling
6. Exceptions
7. Object-oriented programming
8. Modules and packages

## Practice loop

For each topic:

- Read the concept.
- Write a small example from scratch.
- Run it with normal and edge-case inputs.
- Explain the output without executing the code.
- Refactor the solution for clarity.

## Debugging checklist

When a program fails:

1. Read the complete error message.
2. Identify the line that raised the error.
3. Check the input and variable types.
4. Reproduce the smallest failing case.
5. Fix the cause rather than hiding the exception.

## Repository hygiene

Keep virtual environments, Python caches, test caches, IDE files, and local configuration out of version control.
